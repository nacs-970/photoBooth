## Key Decisions Made

- **Stack:** Svelte 5 + Konva.js 10 + Fastify 5 + gphoto2 CLI subprocess (NOT the npm package) + gifenc in Web Worker
- **No Electron** — plain localhost Node server + system browser
- **Adaptive camera** — getUserMedia on Windows, gphoto2 on Mac/Linux; auto-detects at startup
- **All uploads via Node backend** (`/api/share`) — never browser-direct (CORS risk)
- **Always save locally** before/regardless of upload success
- **Template system** — host pre-loads templates in Admin Panel (activate/deactivate); guest browses thumbnail gallery + swipes to pick before each session
