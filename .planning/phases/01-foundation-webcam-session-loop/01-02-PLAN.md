## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-IL | Information Disclosure | Capture Blob lifecycle (objectUrl created when shot saved) | mitigate | `saveShot()` from Plan 01 already revokes prior objectUrl at the same index. No new disclosure surface in Plan 02. |
| T-02-DoS | Denial of Service | Countdown timer leaking on screen switch / repeated taps | mitigate | CountdownScreen tracks the interval/timeout handle and clears it in `onDestroy` / `$effect` cleanup. Start button is disabled while `phase === 'counting'` to prevent double-firing. |

| T-02-SC | Tampering (Supply Chain) | No new packages installed in this plan | accept | All dependencies were vetted in Plan 01. |
</threat_model>
