# Phase 1 — UI Design Contract

> Visual and interaction contract for the Foundation & Webcam Session Loop phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Phase Goal (from ROADMAP.md):** Guest walks up, taps Start, completes a countdown → multi-shot capture → per-shot retake session using getUserMedia.

**Viewing Context:** Kiosk app viewed from ~2–3 feet (standing distance). All sizing and contrast decisions assume this distance, not a desktop reading distance.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (manual tokens) |
| Preset | not applicable |
| Component library | none (custom Svelte components — first phase establishes patterns) |
| Icon library | none in Phase 1 (text-only buttons; icons deferred until Phase 3 needs them) |
| Font | system sans-serif stack: `-apple-system, system-ui, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif` |

Rationale: Project is a Svelte 5 + Vite 8 kiosk app (per STACK.md). shadcn is React-only tooling; shadcn-svelte exists but was not requested in CONTEXT.md and would add weight to a single-screen app. Manual tokens defined here are the source of truth; Phase 3+ may revisit.

## Spacing Scale

Declared values (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline gaps between adjacent text/icon pairs |
| sm | 8px | Compact stacking within a single control |
| md | 16px | Default element spacing, button internal padding |
| lg | 24px | Section padding, gap between progress indicator and thumbnail |
| xl | 32px | Layout gaps, button outer margins |
| 2xl | 48px | Major section breaks, idle screen CTA breathing room |
| 3xl | 64px | Page-level spacing, vertical centering offsets |

**Exceptions:**
- **Minimum touch target: 48px × 48px** (kiosk constraint — guests tap at standing distance). All interactive buttons (Start, Keep, Retake, Retry, Start New Session) must meet this; pad smaller text labels with internal padding to satisfy it.
- **Countdown ring diameter: 240px** — large enough to read across the room while still leaving live preview visible around it.

---

## Typography

Kiosk legibility skews sizes large. Body text at 18px is the floor, display sizes scale for cross-room reading.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 18px | 400 (regular) | 1.5 | Modal body text, microcopy ("2 of 4") |
| Label | 24px | 600 (semibold) | 1.3 | Button labels (Start, Keep, Retake, Retry) |
| Heading | 32px | 600 (semibold) | 1.2 | Modal headings ("Camera disconnected"), confirmation toast ("Photo saved") |
| Display | 96px | 600 (semibold) | 1.0 | Countdown numeral (3 → 2 → 1), idle "Tap to Start" |

**Weights declared:** exactly 2 (400 regular, 600 semibold).
**Sizes declared:** exactly 4 (18, 24, 32, 96).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0F0F12` | Page background, area surrounding live preview, modal scrim background |
| Secondary (30%) | `#1F1F25` | Review screen thumbnail frame/border, modal panel surface, photo grid cell background |
| Accent (10%) | `#FFCC00` | Reserved-for list below |
| Neutral text | `#F5F5F7` | Body text, button labels, headings — paired against dominant/secondary |
| Muted text | `#9A9AA3` | Microcopy ("2 of 4"), modal body |
| Destructive | not used in Phase 1 | (Retake is not destructive — see Copywriting) |

**Accent (`#FFCC00`) reserved exclusively for:**
1. The "Tap to Start" CTA on the Idle screen (button background)
2. The "Start" / "Go" countdown trigger button on the Countdown+Preview screen (button background)
3. The "Keep" button on the Review screen (button background)
4. The countdown progress ring fill (arc/ring color as it depletes)
5. The "Start New Session" button on the Photo Grid stub screen (button background)

**NOT accent (intentionally):**
- Retake button — secondary path, uses neutral surface with neutral text border (`#1F1F25` bg, `#F5F5F7` text, no accent fill)
- Retry button inside the camera-disconnected modal — uses neutral surface (the *modal itself* is the alarm; the button is the path back)
- Any text or icon — accent is a fill color only

**Why dark dominant:** The live webcam feed is the visual focus of the Idle and Countdown screens. A dark chrome lets the camera feed pop and ensures the full-screen white flash (D-12) reads as a flash, not a screen-color shift. Light theme would wash out the review thumbnail and break the flash effect.

## Copywriting Contract

All copy is verbatim — executor uses these strings exactly.

| Element | Copy |
|---------|------|
| Idle screen primary CTA | `Tap to Start` |
| Countdown+Preview trigger button (D-10) | `Start` |
| Countdown numeral (D-11) | `3` → `2` → `1` (numerals only, no "seconds") |
| Review screen progress indicator (D-08) | `Shot {n} of {total}` (e.g. `Shot 2 of 4`) |
| Review screen primary action (D-08) | `Keep` |
| Review screen secondary action (D-08) | `Retake` |
| "Photo saved" confirmation toast (D-09) | `Photo saved` |
| Photo Grid stub heading (D-03) | `Your photos` |
| Photo Grid stub primary action (D-16) | `Start New Session` |
| Empty state (no captures yet) | **Not applicable** — Idle screen with live webcam preview *is* the resting state of the app; there is no separate "no data" state in Phase 1 |
| Error state heading (CAM-04, D-05) | `Camera disconnected` |
| Error state body (CAM-04, D-05) | `Check the cable and try again.` |
| Error state primary action (CAM-04, D-05) | `Retry` |
| Destructive confirmation | **None in Phase 1** — D-07 specifies retake silently overwrites the slot in place; the Review screen itself is the confirm step (Keep vs Retake), so no dialog is needed |

## Component Inventory (Phase 1)

Components established here become the pattern for Phases 2–5. Keep them platform-agnostic — only the Camera Adapter knows about webcam vs gphoto2.

| Component | Purpose | Screens |
|-----------|---------|---------|
| `<LivePreview>` | Renders the `MediaStream` from the active CameraAdapter via `<video>` (Phase 1) or `<img>` MJPEG stream (Phase 2) | Idle, Countdown+Preview |
| `<CountdownRing>` | 240px progress arc with centered Display-size numeral; animates over `countdownMs` (default 3000ms per SESS-01) | Countdown+Preview |
| `<FlashOverlay>` | Full-screen white div, ~300ms fade-out (D-12); triggered on capture | Countdown+Preview |
| `<PrimaryButton>` | Accent-filled button at Label size, ≥48px target | Idle, Countdown+Preview, Review, Photo Grid |
| `<SecondaryButton>` | Neutral-surface button at Label size, ≥48px target | Review (Retake), Modal (Retry) |
| `<ShotProgress>` | Body-size text indicator: `Shot {n} of {total}` | Review |
| `<ReviewPanel>` | Full-size thumbnail + ShotProgress + Keep/Retake buttons | Review |
| `<Toast>` | Heading-size centered "Photo saved" pill, ~1–1.5s display (D-09) | After Keep (between shots) |
| `<DisconnectModal>` | Overlay modal with Heading copy + body + Retry button; preserves session state beneath (D-05) | Any screen (CAM-04 trigger) |
| `<PhotoGrid>` | Grid of captured thumbnails + Start New Session CTA (D-03) | Photo Grid stub (post-session) |

## Screen-Level Visual Anchors

| Screen | Dominant Visual | Accent Surface |
|--------|----------------|----------------|
| Idle | Live webcam preview, full-bleed | Centered `Tap to Start` button |
| Countdown+Preview | Live webcam preview, full-bleed | `Start` button (pre-tap) → CountdownRing (post-tap) |
| Review | Centered full-size thumbnail on secondary surface | `Keep` button (Retake is neutral) |
| Photo Grid stub | Grid of thumbnails on dominant surface | `Start New Session` button |
| Disconnect modal | Dimmed scrim over current screen, centered panel | None (modal itself is the signal; Retry is neutral) |

## Motion & Timing Tokens

These are Claude's-discretion items locked here for the executor.

| Token | Value | Source |
|-------|-------|--------|
| Screen crossfade | 250ms ease-out | D-04 (200–300ms range), choose midpoint |
| Flash fade-out | 300ms ease-out | D-12 suggestion |
| Photo-saved toast display | 1200ms (fade-in 150ms + hold 900ms + fade-out 150ms) | D-09 (1–1.5s range) |
| Countdown ring animation | Linear over `countdownMs` (default 3000ms) | D-11; linear is more honest than easing for a timer |
| Button press feedback | 100ms scale to 0.97 + 50ms return | Default — kiosk needs tactile confirmation |
