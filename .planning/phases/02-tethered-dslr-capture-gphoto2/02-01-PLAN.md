## Phase Goal

**As a** kiosk host, **I want to** choose between Tethered DSLR and Webcam on every boot, **so that** the app always starts in a known camera state and I can use the real DSLR when it is connected.

<objective>
Vertical slice 1: Camera picker foundation. After this plan the app boots to CameraSelectScreen, probes for a DSLR, shows two tiles, and routes to the full Phase 1 session when the host taps Webcam. The DSLR tile appears but selecting it will show DisconnectModal (TetheredAdapter.init() still throws) until Wave 3 implements the real adapter.

Purpose: Establish the `camera_select` screen routing, adapter singleton mutation pattern (setCameraAdapter), and session shape changes that all downstream plans depend on. Lay test scaffolds so Wave 3/4 can add GREEN implementations to pre-existing test files.
Output: Working camera picker (Webcam path), all 42 Phase 1 tests still passing, 2 new test scaffold files committed.
</objective>
