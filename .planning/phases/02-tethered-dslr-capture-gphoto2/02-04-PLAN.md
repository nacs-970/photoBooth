       ```
       async capture(): Promise<Blob> {
         const { session } = await import('$lib/session.svelte.ts');
         if (!session.sessionStartedAt) {
           session.sessionStartedAt = Date.now();
         }
         this.sessionId = session.sessionStartedAt;

         const res = await fetch('/api/camera/capture', {
           method: 'POST',
           headers: { 'Content-Type': 'application/json' },
           body: JSON.stringify({
             shotIndex: session.currentShotIndex,
             sessionId: this.sessionId,
           }),
         });
         if (!res.ok) throw new Error(`Capture failed: ${res.status}`);

         // Re-connect preview: stream was killed during capture.
         // Cache-bust forces a new HTTP connection — no stale img cache.
         if (this.imgEl) {
           this.imgEl.src = `/api/camera/stream?t=${Date.now()}`;
         }

         return res.blob();
       }
       ```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → POST /api/camera/capture | JSON body with shotIndex + sessionId crosses here; primary injection point |
| Node.js → disk (./captures/) | File written via gphoto2 --filename; path must be sanitized |
| Node.js → gphoto2 subprocess | Args passed via array (never string concat) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-06 | Tampering | POST /api/camera/capture — path traversal | mitigate | shotIndex validated as non-negative integer; sessionId validated as plausible timestamp integer; path.resolve() used for all path construction; no string interpolation of untrusted input into shell commands |
| T-02-07 | Tampering | gphoto2 --filename argument injection | mitigate | execFile() with args array — arguments never concatenated into a shell string; gphoto2 is called with ['--filename', filePath] where filePath is path.resolve() of sanitized integers |
| T-02-08 | DoS | Unbounded disk usage via repeated captures | accept | Kiosk single-session use; captures directory is local; Phase 5 adds cleanup. Acceptable for v1 kiosk scope. |
| T-02-09 | DoS | Capture timeout (gphoto2 hangs) | mitigate | execFileAsync timeout: 10_000ms — process killed automatically if gphoto2 hangs; p-queue releases after rejection |
